Benchmark reranker models for ranking

Usage:
  gorse-bench reranker [flags]

Flags:
  -h, --help       help for reranker
      --user-auc   Export user-level AUC scores to CSV file

Global Flags:
  -c, --config string   Path to configuration file
  -j, --jobs int        Number of jobs to run in parallel (default 4)
