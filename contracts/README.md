# Frozen contracts

Everything a Go node and a Rust node must agree on to run in one cluster, captured
from the Go implementation at upstream commit
`add21b53123508e00bdc02bd92290b08603b0236` (see `PORTING.md`).

The Go code is the oracle. Every file here was either copied verbatim from the Go
tree or generated by running the Go code; hand-written files only describe what
the Go code does and cite the source lines they summarise. If a file here and the
Go code ever disagree, the Go code wins and the file is regenerated.

Changing any contract is a decision recorded in `PORTING.md` (decision log). A
Rust crate that cannot meet a contract logs the gap in `PORTING_NOTES.md`; it never
edits the contract to match itself.

| Contract | Files | How it was produced |
|---|---|---|
| gRPC protocol | `proto/*.proto`, `proto/SHA256SUMS`, `grpc.md` | Copied from `protocol/`; `grpc.md` describes who serves what and semantics the `.proto` files leave implicit |
| REST API | `rest/server.openapi.json`, `rest/master.openapi.json`, `rest/*.routes.md`, `rest/README.md` | `go run ./contracts/tools/openapi -node server\|master`; verified equal to the live `/apidocs.json` of a running Go server and master |
| Database schemas | `schema/{data,cache,meta}/*`, `schema/samples/*`, `schema/README.md` | `contracts/tools/dump-schemas.sh` runs the Go stores' own `Init`/`Reconcile` against real MySQL 8.0, Postgres 10, MongoDB 6, Redis 8 and SQLite, then dumps them |
| Cache keys and value encodings | `cache-keys.md` | Catalogued from every cache call site in the Go tree; encodings confirmed by `schema/samples/cache.*.json` |
| Configuration | `config/config.toml`, `config/config.keys.md`, `config/config.schema.json`, `config/meta-config.*.json` | `go run ./contracts/tools/configschema` |
| Model blobs and dump files | `model-blobs.md` | Described from the Go encoders; golden blobs are generated by the conformance suite, not committed |
| Command-line flags | `cli/*.help.txt`, `cli/README.md` | `--help` output of the Go binaries; `README.md` adds behaviour the help text omits |

## Regenerating

The generators for these files were removed with the Go oracle (D-311), so
nothing in this tree regenerates them. They remain in commit `2e9c969`, the
last head with the Go code (branch `go-oracle-final`). Step P0-2 of
`porting/verification-plan.md` restores a hermetic build of that commit. Until
then, the committed files are the frozen record.
