# Work packages

All Go paths are at upstream commit `add21b5` (`PORTING.md`). The order follows
`dependency-graph.md`: a package is ported only after every Gorse package it
imports. Within a phase, packages with no dependency between them can run in
parallel.

Every package follows the definition of done in the project plan (section 7):
Go tests ported first with the same cases and assertions, the acceptance command
passing with its output pasted in the report, `cargo clippy -- -D warnings` and
`cargo fmt --check` clean, doc comments on public items, a `// Ports:` header on
every module, Go errors mapped to `Result`, and reproduced quirks logged in
`PORTING_NOTES.md`.

Backends for Phase 2 come from `storage/docker-compose.yml`. Tests read the same
environment variables as the Go tests (`MYSQL_URI`, `POSTGRES_URI`, `MONGO_URI`,
`REDIS_URI`, `QDRANT_URI`, `MILVUS_URI`, `WEAVIATE_URI`, `S3_ENDPOINT`, ...)
with the values the Go CI uses; a test whose variable is unset fails rather than
being skipped, so a green run always means the backend was exercised.
