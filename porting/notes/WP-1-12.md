Ports `common/decision/client.go`, `common/reranker/client.go` and `common/mock/openai.go`
at add21b5, with their three test files. Rust target: `crates/gorse-common/src/{decision,reranker,mock}.rs`.
The HTTP code the three share lives in `crates/gorse-common/src/http.rs`, a `pub(crate)` module.

Provisional ids: `D-WP12-*`, `Q-WP12-*`, `X-WP12-*`. No `O-` entries: no test in this WP is ignored.

## Decisions

- **D-WP12-1 The test servers use `std::net`, not go-restful or axum.** Go's mocks answer through
  go-restful over `net/http`. The Rust mocks answer through a small HTTP/1.1 server on `std::net`
  (`http.rs`). It serves one request per connection, reads `Content-Length` bodies, and answers with
  `Connection: close`. The mocks serve two routes each. `gorse-common` has no async runtime, so axum
  and tokio would add two dependencies to serve two routes.
- **D-WP12-2 Client calls end when their context does.** `http::post` runs the request on its own
  thread and checks the context every 10 ms. A context that is done returns `Error::Context`, as Go's
  cancelled request does. The request thread finishes unobserved and its reply is dropped.
- **D-WP12-3 The clients use reqwest's blocking client with rustls.** Go's `http.DefaultClient` is
  shared across requests, and so is the Rust `OnceLock` client. Both honour the proxy environment
  variables. No Phase 1 caller is async.

## Quirks reproduced

- **Q-WP12-1 The decision client accepts any 2xx; the reranker client accepts only 200.**
  `common/decision/client.go` checks `200 <= status < 300`. `common/reranker/client.go` checks `!= 200`.
- **Q-WP12-2 Error texts are Go's.** Decision: `jev request failed with status N: <body, trimmed>`.
  Reranker: `rerank request failed with status: N, body: <body>`.
- **Q-WP12-3 Optional request fields are omitted as in Go.** `top_n` is left out when zero
  (`omitempty`). A criteria with neither outcome encodes as `{}`, and a question without criteria
  leaves the field out.
- **Q-WP12-4 The chat mock prefixes replies for model `deepseek-r1` with a `<think>` block**
  (`common/mock/openai.go`, the same branch as Go).
- **Q-WP12-5 Stream pieces are cut by bytes, as Go cuts them.** Eight bytes per piece. A piece can
  end inside a multi-byte character. JSON encoding then writes each invalid byte as U+FFFD, which
  `mock::go_string` reproduces.
- **Q-WP12-6 Embedding input must be a string.** Go answers 400 with `invalid input type`, and the
  Rust mock does the same.

## Deviations

- **X-WP12-1 The OpenAI mock listens on 127.0.0.1, not on every interface.** Go's
  `net.Listen("tcp", "")` listens on all interfaces. Go's reranker mock already binds `127.0.0.1:0`,
  and the Rust reranker mock matches it. Tests connect only to loopback, so the Rust mock keeps
  itself off the network.
- **X-WP12-2 The mock's JSON leaves out two fields.** Go writes `content_filter_results` and the
  unnamed `MultiContent` field on chat messages. The Rust mock writes neither. No Gorse code reads
  either.
- **X-WP12-3 `start()` returns `Ok(())` after `close()`.** Go returns `http.ErrServerClosed`.
- **X-WP12-4 Chunked request bodies get a 400.** Go's server reads them. The Gorse clients send
  `Content-Length` bodies, so no test reaches this path.
- **X-WP12-5 `"answers": null` is a decode error.** Go's nil map accepts it. Serde rejects `null` for
  a `BTreeMap`. No Gorse caller sends null.
- **X-WP12-6 Float32 embeddings are written as `139.0`.** serde_json writes an `f32` with a fraction;
  Go writes `139`. The values are equal, and the Go test compares parsed float32s.
- **X-WP12-7 An empty `messages` list gets a 500.** Go indexes `Messages[0]` without a check, and
  net/http then drops the connection. The Rust mock answers 500 with Go's index-panic text, so the
  failure is visible.
