## What the test does

- `conformance/tests/metrics.rs`, 11 tests, none ignored:
  - Gate 2, the replay (1e-5, D-195): `replay_cf_bpr_and_als_match_go` and `replay_ctr_afm_matches_go`
    run `contracts/tools/modelreplay` live into a temporary directory (with `GODEBUG=randautoseed=0`
    for ctr, as `ctr_replay.rs` does), then fit the Rust models for every epoch count and compare the
    metrics (and, for cf, the final factors). The committed goldens are checked against live Go by
    `cf_golden.rs` and `ctr_replay.rs`.
  - Gate 1, the datasets (D-195): one test per Go model test that loads a built-in dataset, plus the
    commented-out pinterest-20 tests and ml-100k. Each test runs the Go oracle
    `conformance/oracle/metrics` itself, then fits Rust on the same file.
- `conformance/oracle/metrics/main.go`: the Go side. It fits one configuration with the parameters of
  the Go test that uses the dataset, with `SetJobs(runtime.NumCPU())`, and writes the metrics as JSON.
  Its output for ctr includes the marshal round trip.
- `conformance/Cargo.toml`: two dev-dependencies, `gorse-model` and `gorse-model-core`.

## Deviations and choices (for the court)

- D-195 bands: NDCG and accuracy are checked against the value the Go test asserts, with the Go test's
  own delta. Precision, recall and AUC, which the Go tests do not assert, are checked against a Go run of
  the same configuration on the same file, within 0.01 (`benchDelta` and `classificationDelta`).
- Pinterest-20 (`model/cf/model_test.go`, commented out in Go): the value the commented code asserts is
  used as the NDCG reference (0.53 for BPR, 0.52 for ALS), within 0.01. Go does not run these tests.
- ml-100k: no Go test uses it. Its reference is a Go run of the ml-1m configuration (BPR and ALS).
- ml-tag: Go skips the test (`t.Skip`). It runs here, so no check is skipped.
- The ctr clone (marshal round trip) is checked where the Go test checks it (frappe, criteo).
- Go's parallel fits are not deterministic (`SetJobs(NumCPU)`). The measured run-to-run spread is in
  the results section below.
