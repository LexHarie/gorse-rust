## Decisions

- **D-WP8-1 `mysql_dsn` lives in `gorse-common`.** `gorse-storage-core` depends
  on `gorse-common`, and `log` needs `redact_db_url`, which is in `mysql_dsn`.
  Putting `mysql_dsn` in storage-core would make `gorse-common` depend on it,
  a cycle. The module moved with `git mv`, and storage-core re-exports it as
  `pub use gorse_common::mysql_dsn;`, so `gorse_storage_core::mysql_dsn` keeps
  its path.
- **D-WP8-2 Run-time log routing.** The three Go loggers are replaced when
  flags are read. The Rust set-up uses one `tracing` subscriber with a reload
  handle; the access and OpenAI logs are chosen by target inside the writer
  (`Route::make_writer_for`). A per-layer `with_filter` panicked when layers
  were swapped in at run time ("Filtered layer used, but it had no FilterId"),
  so routing moved into the writer.
- **D-WP8-3 Datasets under `~/.gorse`.** `datautil` keeps Go's layout:
  `dataset/<name>` is the unpacked directory and `temp/` holds the download.
  `LoadIris` reads `iris.data` from it. Its target class is `i64`, Go's `int`
  on the 64-bit targets Gorse runs on.
- **D-WP8-4 Test-only dependencies.** `tempfile` 3.27.0 (dev), and the
  `[workspace.dependencies]` additions are `tracing-subscriber` 0.3.23 (`fmt`,
  `json`, `registry`, `std`), `csv` 1.4.0, `reqwest` 0.13.5 (`blocking`,
  `rustls`), `zip` 9.1.3 (`deflate`). Their rows are in
  `porting/crate-selection.md`; the statik row's `zip` is bumped from 9.0.4 to
  9.1.3 so both uses agree.

## Quirks and deviations

- **Q-WP8-1 `sizeof` charges unused slice capacity at 24 bytes per slot.**
  Go's `sizeof` asks for `v.Type().Size()` of the slice type, which is the
  slice header (24 bytes), not the element size, so the unused capacity is
  charged at 24 bytes per slot. Kept on purpose. The expected numbers in the
  `sizeof` tests come from a Go 1.27.0 program run on the same values; that
  program is in the scratch directory and is not committed.
- **X-WP8-1 Log format and the loggers not ported.** Log lines are tracing's
  JSON, not zap's JSON: the field names and the time format differ. Events go
  to stderr as JSON at info level when no set-up has run, as zap's production
  logger does. Not ported: `OptunaLogger`, the OpenTelemetry handler, and
  `ResponseLogger`. Lumberjack removes old backups in a goroutine after a
  rotation; here the removal finishes before the rotation returns.
- **X-WP8-2 `json` NaN and infinity.** Go's `json.Marshal` fails with
  `UnsupportedValueError` on NaN and infinities. `serde_json` writes `null`
  before the formatter sees them, so `marshal` returns `null` where Go errors.
  The test for a failing encoder uses a custom `Serialize` type instead.
- **X-WP8-3 `copier` aliasing and errors.** Go's copy can leave the copied
  slice sharing its backing array with a variable the caller still holds. Rust
  ownership cannot express that, so the port copies. Tests check the reuse of
  the destination's buffer through `as_ptr`. Three Go errors (a destination
  that is not a pointer, a type mismatch, a struct name mismatch) are compile
  errors here, so `copy` returns nothing. See the module doc.
- **X-WP8-4 Home directory.** Go takes the home directory from
  `user.Current()` (the password database) and stops the process if that
  fails. The port reads `$HOME` and uses an empty path when it is unset.
- **X-WP8-5 `datautil` details.** A short CSV row (fewer than five fields) is
  an `Error::ShortRow`; Go panics on the `row[4]` index. Unzipped files get default
  permissions; Go uses `f.Mode()`. The ZipSlip check (`file_path` must be a
  strict descendant of the destination, as Go's `HasPrefix` check requires)
  is ported and tested.
- **X-WP8-6 Monitor and `sync.Map`.** Each span guards its fields with a
  mutex and the maps with mutexes; Go uses `sync.Map` and unlocked updates.
  The same sequence of calls gives the same results, and there are no data
  races.

## Open

- **O-WP8-1 `TestLoadIris` is ignored.** It downloads from `cdn.gorse.io`,
  which this container cannot reach (`curl` gives 000). It is ported as
  `#[ignore = "needs cdn.gorse.io, which this container cannot reach"]`, with
  the same assertions as the Go test (150 rows, 4 values per row, 150 targets).
  It has not been run against the CDN. Offline tests cover the CSV parse and
  the unzip, including a ZipSlip archive.
