# WP-1-15 notes (provisional ids, folded into PORTING.md / PORTING_NOTES.md at merge)

## Float formatting (gostrconv::format_float, format_int, format_uint)

- Q-a (quirk, reproduced): Go's shortest float formatting settles a tie
  between two equally close shortest forms on the even digit; Rust's `{:e}`
  takes the larger. 2^-25 prints as Go's `2.9802322387695312e-08` (Rust
  alone: `...313`), the float32 158164.125 as `158164.12`. `ftoa.rs` takes
  Rust's digits and settles the tie as Go does (`Magnitude::shortest`);
  `ftoa_golden.json` holds 75 such ties among 4,077 floats, every format,
  precision -1..40 and both bit sizes, and fails on all 75 without the rule.
- C-a (correction of earlier work): the `%v` float printers of WP-1-7
  (`gorse-common/src/expression.rs`) and WP-1-19 (`gorse-expr/src/gostr.rs`)
  took Rust's shortest digits as they are, so a feedback type expression or
  an expr-lang float literal at such a tie printed differently from Go. Both
  now call `format_float(v, b'g', -1, 64)`; `gorse-expr` depends on
  `gorse-common` for it. `expression_golden.json` gained 2^-25 (format
  cases) and its decimal form (parse cases); the old code fails them.
- `fmtB` and `fmtX` (`%b`, `%x`, `%X`) are ported too, so Go's ftoa_test.go
  table runs case for case (`tests/gostrconv_go_ftoa.rs`).
- O-a (observation): `gorse-expr/src/gostr.rs` keeps its own copies of
  Go's quote, IsPrint, ParseInt and ParseFloat. Now that it depends on
  `gorse-common`, they could call `gostrconv` (ParseFloat once WP-1-14's
  structural port lands, D-52); not done here, to keep this change to the
  bug.

## Case mapping (gorse-common::gounicode)

- viper lower-cases keys with Go's `strings.ToLower` and mapstructure matches
  them to fields with `strings.EqualFold`; both use Go's simple, one code
  point to one code point mappings from Unicode 17.0.0, not Rust's full
  `to_lowercase` (`İ` → `i`, final sigma stays `σ`). `gounicode` ports
  `unicode.ToLower`, `unicode.SimpleFold`, `strings.ToLower` and
  `strings.EqualFold` over tables Go generates (`contracts/tools/casegolden`);
  `case_golden.json` checks ToLower on every non-ASCII cased code point and
  ~7,000 strings and EqualFold on folding orbits, mixed strings and near
  misses, both ways round.
